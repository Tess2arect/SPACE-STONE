FILES
- index.html: public clue/landing page
- archive/sector-7.html: unlisted clue page (noindex)
- style.css: visual styling
- robots.txt: asks search engines not to index /archive/

IMPORTANT SECURITY NOTES
1. An unlisted URL is NOT private. Anyone who gets the link can open it.
2. Do not put the final answer or secret flag in HTML, JavaScript, comments, filenames, or public GitHub files.
3. For real flag checking, host challenges on a CTF platform such as CTFd, or use a server-side validator.
4. robots.txt is a request to crawlers, not access control.
5. Replace sample clues with facts you have independently verified.

PUBLISH WITH GITHUB PAGES
1. Create a new public GitHub repository, for example: space-stone-ctf.
2. Extract this ZIP on your computer.
3. Upload index.html, style.css, robots.txt, README.txt and the archive folder to the repository root.
4. In GitHub, open Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. Wait for GitHub Pages to publish and open the URL shown in Settings -> Pages.
